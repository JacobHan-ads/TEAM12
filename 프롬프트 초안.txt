[인터페이스 설명]

- 웹 어플리케이션 인터페이스는 streamlit 라이브러리를 사용한다.

- 화면 상단에 'all_appliances_reviews.csv' 파일을 사용자가 직접 브라우저에 드래그하여 업로드할 수 있는 파일 업로더 기능을 배치한다.

- 가전 카테고리(제습기, 냉장고, 세탁기, 청소기) 또는 특정 '제품명'을 사용자가 선택하여 필터링할 수 있는 사이드바 필터(selectbox 또는 multiselect)를 구현한다.

- 필터링된 결과 데이터프레임을 화면에 깔끔한 테이블 형태로 먼저 출력한다.

- 모든 시각화 결과물(그래프 및 텍스트 분석 결과)은 streamlit 메인 화면에 직접 렌더링한다.



[기능 설명]

1. 데이터 로드 및 전처리 함수: 업로드된 CSV 파일을 읽어와 데이터프레임으로 변환하고, 결측치 처리 및 평점 데이터의 타입을 정형화한다.

2. 제품별 평점 분포 시각화: 선택한 제품군의 평점(1점~5점) 분포를 확인할 수 있는 막대 그래프(Bar Chart) 또는 히스토그램을 화면에 출력한다.

3. 부정 리뷰 필터링 및 키워드 추출: 평점 1점~3점 사이의 낮은 리뷰들만 따로 추출한 뒤, 소비자들이 느끼는 가장 치명적인 불만 요소가 '하드웨어 결함' 관련 단어인지 '소프트웨어/사용 편의성' 관련 단어인지 비교 분석할 수 있도록 빈도수가 높은 텍스트 키워드를 추출한다.

4. 불만 여론 시각화: 

   - 워드클라우드(WordCloud): 부정 리뷰 텍스트에서 추출한 핵심 키워드들을 시각화하여 표현한다.

   - 불만 유형 분류 차트: 하드웨어 관련 키워드(소음, 배터리, 진동, 발열 등)와 소프트웨어 관련 키워드(어플, 연동, 조작, 인터페이스, UI 등)의 출현 빈도를 비교하는 막대 그래프를 생성한다.



[데이터 설명]

- 입력 데이터는 '제품명', '카테고리', '작성일자', '평점', '리뷰내용' 컬럼으로 구성된 'all_appliances_reviews.csv' 파일을 기준으로 작동한다.

- 리뷰 내용 분석 시 한글 형태소 분석이나 간단한 단어 포함 여부(contains) 규칙을 기반으로 키워드를 카운트한다.



[코드 작성 요구사항]

- 예외 및 에러 처리 코드를 포함한다 (파일 미업로드 상태 처리, 잘못된 파일 형식 업로드 시 경고 메시지 출력 등).

- 프로그램의 가독성을 위해 기능별(데이터 로드, 필터링, 텍스트 처리, 시각화)로 함수를 명확히 분리하여 정의한다.

- 전체 실행 구조는 main() 함수를 통해 제어되도록 작성한다.

- Matplotlib 또는 Seaborn 시각화 툴 사용 시 한글 폰트가 깨지지 않도록 OS별(Windows/Mac) 폰트 설정 코드를 반드시 포함한다.

- 코드 내에 불필요한 출력을 줄이고 깔끔한 주석을 상세히 작성한다.

- 이모티콘은 절대 사용하지 않는다.
