+ team12-주요 가전 제품군 쇼핑몰 리뷰 분석 및 불만 키워드 도출 프로젝트
+ 
+ [팀원]
+ 경영학전공 202643324 한예호
+ 경제학전공 202642112 김민재
+ 
+ [프로젝트 소개]
+ 온라인 쇼핑몰 내 주요 전자기기 및 가전제품의 리뷰 데이터를 수집하고 분석하는 프로젝트다. 수집된 소비자 리뷰 데이터를 바탕으로 제품별 평점 분포 추이를 파악하고, 평점 1점~3점 사이의 부정 리뷰를 정밀 필터링한다. 이를 통해 소비자가 느끼는 치명적인 불만 요인이 '하드웨어 결함(소음, 배터리, 진동, 발열 등)'인지 혹은 '소프트웨어/사용 편의성(어플 연동, 조작 UI, 터치 등)'인지 비교 분석하며, 워드클라우드 시각화를 통해 핵심 품질 개선 키워드를 한눈에 파악할 수 있도록 돕는다.
+ 
+ [실행방법]
+ 프로젝트를 실행하기 위해 파이썬 터미널에서 다음 절차를 따른다.
+ 
+ 1. 라이브러리 설치
+ - 파이썬 터미널을 열고 필요한 외부 라이브러리(streamlit, pandas, matplotlib, wordcloud)들을 설치한다.
+   명령어: pip install -r requirements.txt
+ 
+ 2. 프로그램 구동
+ - 터미널에 'streamlit run ().py'라고 입력 후 웹브라우저 실행을 기다린다.
+ 
+ 3. 데이터 분석 수행
+ - 브라우저 화면이 뜨면 상단의 파일 업로드 영역에 수집된 데이터 샘플 파일을 드래그 앤 드롭으로 업로드한다. 
+ - 파일이 정상적으로 로드되면 사이드바 필터를 활용해 원하는 가전 카테고리(제습기, 냉장고, 세탁기, 청소기) 및 특정 제품명을 선택하여 동적으로 데이터를 필터링할 수 있다. 
+ - 화면 메인 창에는 필터링된 데이터 리스트와 함께 제품별 평점 분포 그래프, 하드웨어 및 소프트웨어 요인별 불만 유형 분류 차트, 그리고 주요 불만 키워드가 반영된 워드클라우드가 직관적으로 출력된다.
